# Using exported scenes in C

Scene Editor exports a project as plain C11 source for [raylib](https://www.raylib.com/).
The editor does the placement maths you'd otherwise do by hand: where each thing sits in a
level, where each UI box sits on a screen of any size. Each scene becomes a C struct with
one field per entity and UI element, named after it in the editor. Your game reads those
placements and draws its own things there, and the scene scales to any window.

## A whole program

`src/project_main.c` in the export is this, give or take a comment:

```c
#include <raylib.h>

#include "scene_manager.h"

int main(void) {
    static SceneManager scenes;

    SetConfigFlags(FLAG_WINDOW_RESIZABLE);
    InitWindow((int)SCENE_DESIGN_WIDTH, (int)SCENE_DESIGN_HEIGHT, "My game");
    SetTargetFPS(60);
    scene_manager_init(&scenes, SCENE_ID_DEMO);

    while (!WindowShouldClose()) {
        scene_manager_update(&scenes, GetFrameTime()); /* physics */

        BeginDrawing();
        ClearBackground(BLACK);
        scene_begin();                    /* scene coordinates, scaled to the window */
        scene_manager_draw(&scenes);
        DrawCircleV(scenes.demo.sun.pose.position, 20.0f, YELLOW); /* your own drawing */
        scene_end();
        scene_manager_draw_ui(&scenes);   /* the UI, in window pixels */
        EndDrawing();
    }

    scene_manager_deinit(&scenes);
    CloseWindow();
    return 0;
}
```

## Conventions

- **Fixed hierarchy:** which entities exist, their parents and their components are fixed
  at export. Change their fields (transforms, sprites, `visible`, labels) at runtime; to
  add or remove things, change the scene in the editor.
- **Names:** a field is named after its entity in lower case, with anything that isn't a
  letter or digit turned into `_` ("Health Bar" becomes `health_bar`). Repeated names get
  `_2`, `_3`; names starting with a digit get an `e_` prefix.
- **Coordinates:** scene coordinates have (0, 0) at the scene origin, which shows at the
  centre of the screen. Y points down, and rotations are in degrees, clockwise on screen.
  UI coordinates are window pixels: see [UI](ui.md).
- **Generated files:** generated files start with `// Generated by Scene Editor` and are
  replaced on every export, except the files you may edit by hand (Makefile,
  `src/project_main.c`, `.vscode` settings, `.gitignore`), which follow the
  [export options](getting-started.md#export-options). Put your own code in `src/`.
- **C++:** every header has `extern "C"` guards, so C++ games can use them directly.
