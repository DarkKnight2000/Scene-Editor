# Using exported scenes in C

Scene Editor exports a project as plain C99 source for [raylib](https://www.raylib.com/).
You build it with your game, and scenes become runtime data: entities and components you
can read, change, add and remove while the game runs.

## The shortest working program

This program draws one scene. Here it's the scene called `demo`; every scene `<name>` in
your project has a matching `scene_<name>_load` and `scene_<name>_draw`.

```c
#include <raylib.h>

#include "scenes.h"

int main(void) {
    static SceneData demo; /* zero-initialised: a valid, empty scene */
    int current = SCENE_ID_DEMO;

    InitWindow(1280, 720, "My game");
    SetTargetFPS(60);
    scene_demo_load(&demo); /* build the scene's entities (after InitWindow) */

    while (!WindowShouldClose()) {
        BeginDrawing();
        ClearBackground(BLACK);
        scene_begin(SCENE_DEFAULT_SCALE_MODE); /* scale the design area to the window */
        scene_demo_draw(&demo, &current);
        scene_end();
        scene_draw_ui(&demo, SCENE_DEFAULT_SCALE_MODE); /* the scene's UI, on top */
        EndDrawing();
    }

    scene_unload(&demo);
    scene_memory_destroy();
    CloseWindow();
    return 0;
}
```

With several scenes, let a [SceneManager](scenes.md#the-scenemanager) hold them all.

## Conventions

- **Coordinates:** scene coordinates have (0, 0) at the scene origin, which shows at the
  centre of the screen. Y points down, and rotations are in degrees, clockwise on screen.
  UI coordinates are different: see [UI](ui.md#coordinates).
- **Ids:** entity ids are `int`s that index the scene's arrays. Functions return `-1` for
  "no entity" or "failed".
- **Pointers into the scene:** pointers returned by the API point into the scene's arrays.
  Adding entities or components can move those arrays, so get a fresh pointer after
  adding instead of keeping one. Each function's notes say exactly when a pointer stays
  valid.
- **Generated files:** generated files start with `// Generated by Scene Editor` and are
  replaced on every export. Put your own code in `src/`, which the export never touches
  apart from `src/project_main.c`.
- **C++:** every header has `extern "C"` guards, so C++ games can use them directly.
